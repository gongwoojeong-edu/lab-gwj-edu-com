
## 요청 정리

기존 localStorage에 저장된 customAnswers를 모두 비우고 정답 입력 모드에서 처음부터 새로 입력하고 싶음.

## 현재 상태

- `src/lib/customAnswers.ts`에 이미 `clearCustomAnswers()` 함수 존재 (localStorage `gwj.customAnswers.v1` 키 제거)
- `Index.tsx`에 `[정답 초기화]` 버튼이 정답 입력 모드일 때 헤더에 노출되어 있음 (이전 승인된 플랜)

## 두 가지 방법

### A) 가장 빠른 방법 — 사용자가 직접 클릭
1. 헤더 우측 `[✏️ 정답 입력 모드]` 토글 ON
2. 그 옆/아래 나타나는 `[정답 초기화]` 버튼 클릭 → 확인 → 모든 customAnswers 삭제
3. 이후 입력하는 모든 답이 새 데이터로 저장됨

### B) 만약 [정답 초기화] 버튼이 안 보이거나 동작 안 하면
- 점검 항목:
  - 헤더에 버튼이 실제 렌더되는지 (`answerInputMode === true` 조건)
  - `clearCustomAnswers()` 호출 후 `progressMap` 같은 화면 state도 초기화되는지
  - 확인 다이얼로그(AlertDialog)로 실수 방지 처리 여부

필요하면 다음을 보강:
| 변경 | 내용 |
|---|---|
| `Index.tsx` | `[정답 초기화]` 버튼 가시성·동작 점검, 클릭 시 `clearCustomAnswers()` + 현재 문장 `progressMap` 리셋 + 토스트 "정답 데이터를 모두 삭제했습니다" |
| (옵션) | 확인 다이얼로그 추가 — "정말 모든 정답을 삭제하시겠습니까? 되돌릴 수 없습니다." |

## 진행 범위
- ✅ 정답 입력 모드 토글 ON 상태에서 `[정답 초기화]` 버튼이 명확히 보이도록 점검·보강
- ✅ 클릭 시 localStorage 완전 삭제 + 화면 즉시 반영 + 토스트 알림
- ✅ 실수 방지용 확인 다이얼로그 추가
- ❌ 정답 export/백업 기능은 이번 범위 아님 (요청 시 별도 추가)

먼저 사용자가 직접 헤더의 `[정답 초기화]` 버튼을 눌러봐 주세요. 안 보이거나 눌러도 데이터가 안 사라지면 위 보강 작업을 즉시 진행합니다.
