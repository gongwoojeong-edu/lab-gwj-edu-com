

## 헤더 버튼들을 하단으로 내려서 분석 패널 살리기

### 아이디어 정리

사용자 제안대로 **헤더를 가볍게 만들고, staff 도구는 하단 고정 바(bottom toolbar)** 로 옮기면 분석 패널이 가려지지 않습니다. 헤더 높이 자체가 줄어드니 `top-[68px]` 가 다시 충분한 여유가 됩니다.

### 새 레이아웃

```text
┌─────────────────────────────────────────────────────────┐
│ [로고/제목]   [학습 진행 상태]              [사용자]     │ ← 헤더 (얇게, ~56px)
├─────────────────────────────────────────────────────────┤
│                                       ┌──────────────┐  │
│   문장 / 토큰 영역                    │ 분석 패널    │  │
│                                       │ 레이어 01..  │  │ ← 가려지지 않음
│                                       │ POS / ...    │  │
│                                       └──────────────┘  │
├─────────────────────────────────────────────────────────┤
│ [정답입력] [정답저장] [정답초기화] │ [AI추출][단어목록][힌트] │ ← 하단 staff 바
└─────────────────────────────────────────────────────────┘
```

### 변경 계획 (`src/pages/Index.tsx` 단일 파일)

#### 1. 헤더 슬림화

- 헤더 우측에서 `정답 입력 / 저장 / 초기화 / AI 추출 / 단어 목록 / AdminHintToggle` 전부 제거.
- 남는 항목: **로고/제목**, **학습 진행 상태(`StepProgressBar`)**, **사용자 메뉴** 만.
- 모바일 ⋯ 도구 드롭다운도 제거(하단 바가 그 역할 대체).
- 결과: 헤더 높이 ~56px 정도로 안정화 → 한 줄 유지.

#### 2. 하단 staff 툴바 신설

- 새 컴포넌트 영역(같은 파일 안 JSX 블록)으로 `<div className="fixed bottom-0 inset-x-0 z-40 ...">` 추가.
- `isStaff` 일 때만 렌더 (학생은 화면 100% 깨끗).
- 내부 구조:
  - 좌측 그룹: `[정답입력 모드 토글] [정답 저장] [정답 초기화]`
  - 구분선
  - 우측 그룹: `[AI 추출] [단어 목록] [힌트 설정]`
- 스타일: `border-t border-border/60 bg-background/85 backdrop-blur-sm shadow-[0_-4px_12px_rgba(0,0,0,0.05)] px-4 py-2 flex items-center gap-2`.
- 바 높이 약 56px → 본문 하단에 패딩 `pb-20` 추가해서 콘텐츠가 안 가리도록.

#### 3. 분석 패널 위치 보정

- `fixed top-[68px] right-4` → `fixed top-[64px] right-4 bottom-20 z-30` 로 변경.
  - 위는 얇아진 헤더 바로 아래.
  - 아래는 새 staff 바 위에서 멈춤(`bottom-20`).
- `maxHeight` 대신 `bottom` 으로 제한 → 패널 내부 스크롤 자연스럽게.
- 결과: 레이어 01/02/03 영역이 **항상 첫 화면에 노출**.

#### 4. 모바일 처리

- 하단 staff 바도 좁은 화면에서는 가로 스크롤(`overflow-x-auto`) 또는 두 줄 wrap 허용.
- 분석 패널은 기존 모바일 동작(시트/인라인) 유지.

#### 5. 기존 기능 유지

- `?` 단축키로 분석 패널 토글, 플로팅 복구 버튼은 그대로.
- 학생 화면: 헤더만 보이고 하단 바 없음 → 더 깨끗.

### 변경 파일

| 파일 | 변경 |
|------|------|
| `src/pages/Index.tsx` | 헤더에서 staff 버튼 제거, 하단 fixed staff 툴바 신설(isStaff 가드), 분석 패널 `top/bottom` 재조정, 본문 `pb-20` |

### 동작 결과

- **현재 1617px (staff)**: 헤더 한 줄(얇음) + 우측 분석 패널이 레이어 버튼부터 다 보임 + 하단 staff 바.
- **모바일**: 헤더 깔끔, 하단 바 가로 스크롤로 모든 staff 도구 접근 가능.
- **학생**: 헤더+본문만, 하단 바 없음.
