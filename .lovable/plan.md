

## LAYER 03 보강 — 문장성분 + 세부역할 분리

이전 플랜에 빠진 **문장성분(S/V/O/C/M) 단계**를 LAYER 03 안에 명시적으로 분리해서 추가합니다. 즉 LAYER 03이 두 단계(3a, 3b)로 나뉘어 학생이 먼저 문장성분을 고르고, 그 후에 해당 성분에 맞는 세부역할 칩만 보이게 합니다.

### 새 LAYER 구조 (명사 라인)

```text
LAYER 01 : 품사
  ⓝ명사  ⓥ동사   (형/부/기타는 disabled)

LAYER 02 : 형태 (명사일 때)
  ①명사   ⑤to V   ⑧V-ing   ⑪접SV

LAYER 03a : 문장성분
  S(주어)  O(목적어)  C(보어)  M(수식어)  // V는 동사 라인에서

LAYER 03b : 세부역할  ← 03a 정답 후 그에 맞는 항목만 노출
```

### LAYER 03b 세부역할 매핑

| 03a 성분 | 형태(공통: 명사·to V·V-ing) | 형태별 추가 |
|---|---|---|
| **S 주어** | 주어, 가주어, 진주어 | to V: 의미상주어 / V-ing: 의미상주어 |
| **O 목적어** | 목적어(타동), 목적어(전치), 간접목적어, 직접목적어, 가목적어, 진목적어 | — |
| **C 보어** | 주격보어, 목적격보어 | — |
| **M 수식어** | (해당 없음 → 형용사/부사 라인에서 처리) | — |

**형태 전용 칩 (성분 무관)**:
- to V → 의문사(to V), 부정형, 수동형, 완료형, 진행형, 원형부정사, 대부정사
- V-ing → 부정형, 수동형, 완료형
- 접SV → 명사절that, whether/if, 의SV, 관대what, 복합관대~ever
  → 이들은 03a 건너뛰고 바로 03b 단일 선택

### 동사 라인 (변경 없음)
LAYER 01에서 ⓥ동사 정답 → 다중선택 패널(수/시제/형/태/대동사) → `✱동사 확정`. 동사는 03a/03b 분리 없음.

### 채점 흐름 (명사)
```text
ⓝ명사 ✓ → ① ⑤ ⑧ ⑪ 중 정답 선택
       ✓ → S O C M 중 정답 선택 (03a)
              ✓ → 해당 성분의 세부역할 칩만 노출 → 정답 선택 (03b)
                     ✓ → 분석 완료 + koreanLabel 표시
```

### 데이터 스키마 보강

```ts
type NounAnswer = {
  pos: "명사";
  form: "명사" | "to V" | "V-ing" | "접SV";
  element?: "S" | "O" | "C" | "M";   // 접SV·형태전용칩일 땐 생략 가능
  role: string;                        // "주어" | "목적어(타동)" | "명사절that" 등
};
```

샘플 마이그레이션 예:
- `She` → `{pos:"명사", form:"명사", element:"S", role:"주어"}`
- `to improve` → `{pos:"명사", form:"to V", element:"O", role:"목적어(타동)"}`
- `English` → `{pos:"명사", form:"명사", element:"O", role:"목적어(타동)"}`
- `mine` → `{pos:"명사", form:"명사", element:"C", role:"주격보어"}`

### UI 디자인
- LAYER 03a: S/O/C/M 칩은 기존 element 색상 톤(element-s/o/c/m) 재활용 → 시각적 연속성 유지
- LAYER 03b: 작은 pill 칩 그리드(2~3열), 03a 정답 시점에 부드럽게 페이드 인
- 형태가 `접SV` 또는 형태 전용 칩이 정답인 경우 03a 자동 스킵 표시 (회색 "—")
