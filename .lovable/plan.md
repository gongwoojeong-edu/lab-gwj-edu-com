# 과 전체 워크북 간편 출력

## 목표
교재 보관함에서 `5과 전체 워크북`, `6과 전체 워크북`처럼 **현재 과의 모든 유닛을 한 번에 선택하여 출력**할 수 있게 합니다.

## 변경 내용
1. **과 전체 워크북 버튼 추가**
   - 각 과 화면 상단에 현재 교재명을 반영한 `5과 전체 워크북` 형태의 버튼을 둡니다.
   - 버튼을 누르면 그 과에 속한 모든 유닛이 자동 선택되고 인쇄 창이 바로 열립니다.
   - 기존의 유닛별 체크 선택과 `워크북 인쇄` 기능은 그대로 유지합니다.

2. **출력 대상 명확화**
   - 인쇄 창에서 학생 한 명을 선택합니다.
   - 기본 워크북 종류는 현재 권장 형식인 **구문 통합본(분석·첨삭)**으로 엽니다.
   - 필요하면 기존처럼 구문 유닛별, 문장별, 단어 워크북, 답지로 바꿀 수 있습니다.

3. **전체 지문 포함**
   - 학습 완료 여부와 관계없이 해당 과의 모든 유닛과 모든 지문을 포함합니다.
   - 학생 답안이 없는 문장은 인쇄를 막지 않고 미제출/빈칸 상태로 표시합니다.
   - 지문이 없는 유닛이나 출력할 내용이 전혀 없는 경우에는 이유를 화면에 알립니다.

4. **확인**
   - 5과와 6과에서 버튼명이 각각 올바르게 표시되는지 확인합니다.
   - 버튼 한 번으로 전체 유닛 선택과 인쇄 창 열기가 되는지 확인합니다.
   - 학생 선택 후 전체 과가 한 문서로 생성되는지, 미완료 지문도 포함되는지 확인합니다.

## 기술 세부사항
- 기존 교재별 유닛 목록과 다중 유닛 워크북 생성 기능을 그대로 재사용합니다.
- 과 전체 버튼은 현재 교재의 모든 유닛 ID를 선택 상태에 넣고 기존 인쇄 창을 엽니다.
- 데이터베이스 변경 없이 화면과 출력 연결 로직만 수정합니다.
