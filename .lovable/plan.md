## 변경 내용

### 부배지 — 번호↔라벨 밀착 + 층별 색 대비 강화

`src/index.css`

- `.sub-badge-pill`
  - `gap-0.5` → `gap-0` (번호와 한글 사이 간격 제거)
  - `px-1.5` → `px-1` (좌우 padding 축소)
- `.sub-badge-num`
  - 크기 `size-3` → `size-[14px]`, 우측 `mr-0.5`
  - 배경: 흰색 반투명 → **각 layer hue의 진한 톤**, 글자색 **흰색**으로 통일 (가독성 ↑, 분석 색상과 직결)
- 층별 색 대비 강화 (텍스트 / 번호 배경 / border 모두 같은 hue 계열로)
  - **Layer 1** violet — 단층은 숫자 숨김 유지 (영향 없음)
  - **Layer 2** amber: 텍스트 `38 95% 28%`, 번호 배경 `38 95% 45%`, border `/0.7`
  - **Layer 3** crimson: 텍스트 `350 78% 32%`, 번호 배경 `350 78% 48%`, border `/0.7`
  - **Layer 4** teal: 텍스트 `175 75% 22%`, 번호 배경 `175 75% 36%`, border `/0.7`
- pill 자체의 배경 채도/투명도는 그대로 (`/0.18~0.22`) → 텍스트·번호만 진하게 떠 보이도록

`src/pages/Index.tsx`
- 구조 변경 없음. 기존 `sub-badge-pill-N` / `sub-badge-num` 클래스가 그대로 새 스타일을 받음.

## 검증

1. ②, ③ 숫자가 한글 라벨에 딱 붙어 보임 (사이 공백 없음)
2. 번호 동그라미가 layer별 진한 색 + 흰 글자로 또렷
3. Layer 2(amber) / Layer 3(crimson) / Layer 4(teal)이 한눈에 구별
4. 단층 owner는 숫자 숨김 유지
5. 분석 텍스트 색과 부배지 색 톤이 일관되게 매칭
