# 배아은 9월 모의고사 "22번까지만 표시" 원인 확인

## 확인 결과 (조사 완료)

- 재학습(다시하기) 잠금이 원인이 아님을 DB로 확인:
  - `sentence_progress`의 미해결 재학습 요청은 모두 7~8월의 이전 교재 문장이며, 대부분 재학습 후 pass 상태.
  - 현재 9월 모의고사(18~43번)에는 재학습 요청 없음.
  - 오늘(9/9) 20번 지문 마지막 문장(`20-1-alt5-5`)까지 정상 pass, 현재 21번 진행 중.
- 18~43번 26개 지문묶음(260문장)은 모두 등록되어 있어 데이터 누락도 아님.

## 결론

학생 진도가 21번이라 그 이후 지문이 화면에 아직 안 보이는 정상 동작으로 판단됨.

## 후속 조치 (필요 시)

- 학생이 본 화면이 **교재 목록/진도 화면**이라면, 미진행 지문도 미리 보여줄지 여부를 확인 후 표시 방식 개선을 별도 계획으로 진행.
- 사용자에게 캡처를 요청해 어떤 화면인지 확인 대기 중.
