# 첨삭퀴즈 학생 화면 수정

## 목표
첨삭퀴즈를 일반 한글해석 재학습과 분리해, 학생이 문제 문장의 원문과 답변 입력란을 한 화면에서 확인하도록 수정합니다.

## 변경 사항
- 미답변 또는 오답 첨삭퀴즈 진입 시 전용 화면을 유지합니다.
- 전용 화면 상단에 해당 영어 원문과 문장 코드를 표시합니다.
- 자유 입력형 질문은 답변 입력란과 제출 버튼이 항상 명확하게 보이도록 합니다.
- 이미 답변한 질문은 제출 완료 상태를 보여주고, 다음 진도로 자동 연결합니다.
- 이지호 학생의 실제 문제 문장으로 입력, 제출, 다음 진도 이동을 검증합니다.

## 기술 사항
- 기존 문장 학습 화면과 첨삭 문답 패널만 수정합니다.
- 재학습 및 한글해석 데이터 처리 방식은 변경하지 않습니다.
