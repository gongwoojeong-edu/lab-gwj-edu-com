
## 의도 정정

부속 배지에서 **하단 SVOC 배지와 중복되는 문장성분 한글만 제거**.

- 하단 SVOC 배지(S/V/O/C/M)에 이미 표시되는 항목 → 부속 배지에서 한글 문장성분(주어/동사/목적어/보어/수식어) 텍스트 제거
- 하단 배지에 표시 안 되는 부속 전용 항목(전치사의 o, to V의 o, V-ing의 o 등) → **그대로 유지** (중복 아니므로)

## 탐색 필요

`AnalysisPanel.tsx` / `Index.tsx` / `WordChip.tsx`에서 부속 배지가 어떤 element 라벨을 한글로 출력하는지 확인:
- 어떤 분기가 "주어/동사/목적어/보어/수식어" 한글을 직접 렌더하는가
- "전치사의 목적어", "to V의 목적어" 같은 합성 라벨은 element 한글이 아니라 별도 부속 라벨이므로 건드리지 않음

핵심 판단: **부속 배지 텍스트가 단독 element 한글(주어/동사/목적어/보어/수식어)이면 제거, 합성/부속 전용 라벨이면 유지**.

## 변경 계획

### 부속 배지 렌더 위치 (탐색 후 확정)
- 단독 element 한글 라벨("주어"/"동사"/"목적어"/"보어"/"수식어") 출력 분기 → 제거 또는 빈 문자열 처리
- 합성/부속 전용 라벨("전치사의 o", "to V의 o", "V-ing의 o", 절의 부속 등)은 그대로 출력

### POS 배지 (명/형/동/부/기타)
- 이전 단계에서 잘못 제거됐다면 **복원**

## 손대지 않을 것
- 하단 SVOC 배지
- 합성 부속 배지 (전치사의 o, to V의 o, V-ing의 o 등)
- 한국어 의미 라벨 (단어 위)
- 1~5번, 7번 작업 결과
