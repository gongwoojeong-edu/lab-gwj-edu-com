# 승인-평가 창 2분할 + 드래그 분할선

## 배경
승인-평가 창(`선생님 승인 — 평가`)에서 지문이 길면 상단의 한글해답·원문·학생해석 세 칸이 화면 대부분을 차지해, 아래쪽 코칭 메모 입력란과 평가 등급 버튼이 화면 밖으로 밀려납니다. (첨부 화면처럼 768px 높이 화면에서 코칭 입력란이 아예 보이지 않음)

## 목표
- 상단 영역(한글해답 / 원문 / 학생 한글해석)과 하단 영역(평가 등급·칭찬·이전 첨삭·코칭 메모·질문 패널)을 2분할
- 두 영역 사이에 **드래그로 조절 가능한 분할선**을 넣어 선생님이 직접 높이 비율을 조절
- 각 영역은 자체 스크롤 — 내용이 길어도 서로를 밀어내지 않음

## 구현 내용

### 1. 분할 레이아웃 (`src/components/learning/TeacherApprovalDialog.tsx`)
- 현재 구조: 헤더(고정) → 상단 참고 블록(`shrink-0`, 높이 제한 없음) → 하단 스크롤 본문(`flex-1`) → 푸터(고정)
- 변경:
  - 상단 참고 블록을 `shrink-0` 대신 **비율 기반 높이**(예: 전체 가용 높이의 45%)로 바꾸고 `overflow-y-auto` 적용 → 긴 지문은 상단 안에서 스크롤
  - 하단 본문은 나머지 높이를 차지하며 기존처럼 자체 스크롤
  - 헤더·푸터는 지금처럼 고정 유지

### 2. 드래그 분할선
- 두 영역 사이에 가로 그립 바(마우스/터치 모두 지원, Pointer Events 사용)
- 드래그 중 비율을 state로 갱신, 최소 20% ~ 최대 75% 범위로 제한(한쪽이 완전히 사라지지 않도록)
- 분할선에 시각적 힌트(가운데 짧은 그립 표시, 호버 시 강조)

### 3. 위치 기억
- 조절한 비율을 선생님 모드 로컬 저장소(`gwjt*` 접두사)에 저장해 다음에 창을 열어도 같은 비율 유지

### 4. 기존 기능 보존
- 원문/한글해답/학생해석 각각의 "수정" 버튼, 정답 보기/가리기 토글, 판서 도구 모음, 티칭 오버레이 동작 그대로
- 수정 모드(Textarea 편집 중)일 때는 해당 칸이 상단 영역 안에서 스크롤되며 편집 가능

## 기술 참고
- 대상 파일: `src/components/learning/TeacherApprovalDialog.tsx` (962행, 레이아웃은 506~962행)
- 상단 블록: 564~737행 (`relative shrink-0 ... space-y-2`)
- 하단 본문: 739행 (`overflow-y-auto flex-1 min-h-0 ...`)
- 분할 비율 state: `const [splitRatio, setSplitRatio] = useState(0.45)` + Pointer Events(`onPointerDown/Move/Up`)로 구현, 외부 라이브러리 불필요
- 저장 키 예: `gwjt.approvalSplitRatio`

## 확인 방법
- 긴 지문(올림포스 12강 11번처럼 원문·해석이 긴 문장)의 승인창을 열어 코칭 입력란이 첫 화면에 보이는지 확인
- 분할선을 드래그해 상하 비율이 바뀌고, 창을 닫았다 열어도 유지되는지 확인
- 원문/해석 수정 버튼, 판서, 티칭 시작이 정상 동작하는지 확인
