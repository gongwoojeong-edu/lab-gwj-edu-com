# 주간·월간 첨삭 리포트 — 자동 생성, 수동 발송 (앱 열람 + 인쇄)

## 목표
선생님이 기간(주간/월간)을 고르면 학생별 첨삭 리포트 초안이 **자동으로 집계**되고, 확인 후 **발송 버튼**으로 학생 앱에 전달한다. 같은 화면에서 **인쇄/PDF 저장**도 가능하다.

## 확정된 요구사항 (사용자 답변)
- 발송 대상·방식: **학생 앱 열람 + 인쇄/PDF** 둘 다 (이메일은 나중에)
- 발송 시점: **자동 생성 + 발송은 수동** (페이지를 열면 초안 자동 집계, 발송은 버튼)
- 내용: 학습량·등급 요약 / 첨삭 메모 모음 / 재학습·취약 유형 / 단어·핸드아웃 성적 — 전부

## 화면 구성

### 1. 선생님: 리포트 발송 화면 (신규 페이지 `/teacher/coaching-reports`)
- 기간 프리셋 버튼: **이번 주 / 지난 주 / 이번 달 / 지난 달 / 직접 선택**
- 학생 선택: 전체 선택 기본, 체크로 개별 제외 가능
- 기간·학생이 정해지면 학생별 리포트 초안이 **자동 집계**되어 카드로 표시
- 학생별 카드에 **[앱으로 발송] [인쇄/PDF]** 버튼 + 상단에 **선택 학생 일괄 발송** 버튼
- 이미 발송한 기간은 "발송완료" 배지 표시 (중복 발송 방지, 재발송은 가능)

### 2. 학생: 리포트 열람
- 발송 시 `student_notifications`에 알림 생성 (기존 알림벨 인프라 재사용, kind="evaluation")
- 알림을 누르면 **학생용 리포트 화면**(신규 `/student/report`)에서 전체 내용 열람
- 학생은 본인 것만 조회 (기존 RLS 정책 그대로)

### 3. 인쇄/PDF
- 선생님 화면에서 인쇄 버튼 → 기존 `printTemplates` 방식의 인쇄 전용 레이아웃 (학생 1명당 1장, A4)
- 브라우저 인쇄 대화상자에서 PDF 저장 가능

## 리포트 내용 (학생 1명 기준)
1. **학습량·등급 요약**: 기간 내 승인(통과) 문장 수, 등급 분포(매우잘함/잘함/보통/미흡/코칭/재학습), 받은 칭찬 메시지 모음
2. **첨삭 메모 모음**: 문장 코드 + 등급 + 선생님 코칭 메모를 날짜순 나열 (기존 `StructuredMemoView` 재사용)
3. **재학습·취약 유형**: 재학습 지정 횟수, 코칭 메모 4개 항목(No skipping/No guessing 등)별 지적 빈도 집계
4. **단어·핸드아웃 성적**: 기간 내 단어테스트 평균/최저 점수, 단어HO·구문HO 기록

## 데이터 소스 (모두 기존 테이블, 스키마 변경 없음)
- `sentence_approvals` (status=approved, 기간 필터) — 등급·메모·칭찬
- `sentence_attempt_logs` — 분석 정답률
- `word_test_results` — 단어 점수
- `handout_results` — 단어HO/구문HO
- `analysis_review_requests` — 재학습 요청 횟수
- `student_notifications` — 발송 기록 겸 학생 알림 (기존 테이블 재사용)
- 집계 로직은 기존 `EvaluationReports.tsx`의 조회 방식을 재사용·확장

## 기술 메모
- 신규 파일: `src/pages/teacher/CoachingReports.tsx`, `src/pages/student/StudentReport.tsx`(또는 기존 학생 화면 내 섹션), `src/lib/coachingReport.ts`(집계 로직), 인쇄 템플릿은 `printTemplates.ts`에 추가
- 라우트: `src/App.tsx`에 2개 추가, 교사 홈 타일에 "리포트 발송" 추가
- 발송 = `student_notifications` insert 1건/학생 (title: "9월 4주 첨삭 리포트", body: 요약). 중복 발송 방지는 같은 기간+학생의 기존 알림 조회로 판단
- 이메일 발송, 자동 정기 발송(pg_cron)은 이번 범위에서 제외
- DB 스키마 변경 없음 (마이그레이션 불필요)

- 인쇄 미리보기 화면 렌더링 확인
