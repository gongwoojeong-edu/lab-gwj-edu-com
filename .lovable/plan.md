# 단어 표기 개선 + 구문분석 "필수 분석 지점" 검수 강화

## 1. 단어 추출 표기 개선 (앞으로 생성되는 자료부터)

지금은 단어마다 `word / meaning / pos(명사·동사·형용사·부사)`만 저장돼서
시제·분사·수동 같은 형태 정보가 드러나지 않습니다.

- AI 추출(`extract-sentence-words`)이 단어마다 추가 정보를 함께 내도록 확장
  - `base`: 원형 (예: `driven` → `drive`)
  - `form`: 형태 표기 (예: `과거분사`, `현재분사`, `과거형`, `복수형`, `비교급`, `to부정사`, `동명사`)
  - `pos`: 지금처럼 4품사 유지 (기존 화면 호환)
- 뜻 규칙 강화: 품사·형태에 맞는 한국어 뜻 (예: 과거분사면 "~된", 동명사면 "~하기")
- 화면 표기
  - 책장 지문의 추출 단어 팝업, 정답설정 단어 목록, 단어 테스트 문항에
    `단어 (원형 · 형태) · 품사 · 뜻` 형태로 노출
  - `base`/`form`이 없는 기존 데이터는 지금과 똑같이 보이도록 처리 (소급 재추출 없음)
- 교사가 팝업에서 형태 표기도 직접 수정/삭제 가능

## 2. 구문분석: 비율 게이트 → 필수 지점 게이트

### 선생님(마스터 입력)
- 마스터키 입력 모드에서 각 단어/구를 선택하면 **"필수 분석"** 토글이 나타남
- 토글을 켠 지점은 마스터 답안에 `필수` 표시가 붙고, 분석 화면에서 별도 색/아이콘으로 구분
- 유닛 전체 마스터 목록에서 현재 몇 개가 필수로 지정됐는지 확인 가능

### 학생
- 다음 단계(한글해석)로 넘어가는 조건이 **"필수 지점 전부 분석 완료"** 로 바뀜
  - 비율(30% / 학생별 `analysis_pass_threshold`) 조건은 필수 지점이 지정된 문장에서는 사용하지 않음
  - 필수 지점이 하나도 지정되지 않은 문장은 지금 정책(비율) 그대로 유지 → 기존 자료 영향 없음
- 미완료 시 안내: "아직 분석해야 할 곳이 N군데 남았어요" + 해당 단어/구 하이라이트
- 승인 요청·첨삭 화면에도 필수 지점 충족 여부가 그대로 반영

## 기술 메모

- 필수 표시는 별도 테이블 없이 admin `owner_progress.progress` JSON에 `required: true` 로 저장
  (마스터 저장 경로 그대로 사용, 마이그레이션 불필요)
- `analysisGrading.ts`
  - `isRequiredMaster`: 명시적 `required` 플래그가 하나라도 있으면 그것만 필수로 판정,
    없으면 현재 휴리스틱(주절 S/V, 절의 V) 유지
  - `requiredOwnersFilled`: 현재의 `safeRate >= 0.3` 우회 제거, span↔단어 토큰 커버리지 판정은 유지
- `SentenceLearn.tsx`: `canProceed` 계산을 `hasRequiredSpots ? requiredOwnersFilled : rate >= gate` 로 변경,
  안내 문구/미완료 owner 목록 표시 추가
- `AnalysisPanel.tsx` + `Index.tsx`: 마스터 모드에서만 보이는 "필수 분석" 토글과 배지 렌더링
- `extract-sentence-words/index.ts`: tool schema에 `base`, `form` 추가 + 시스템 프롬프트 보강
  (`ExtractedWord` 타입, `wordExtraction.ts` 저장/정리 로직, 단어 표시 컴포넌트 동반 수정)
