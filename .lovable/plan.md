# 학생용 "보류함" — 승인 전에도 원문·내 해석 다시 보기

## 문제
지금 학생이 원문 + 자기 해석을 볼 수 있는 곳은 **승인 대기 화면(ApprovalWaitingPanel)** 뿐입니다.
선생님이 "보류"로 넘기면 학생은 곧바로 다음 문장으로 넘어가므로 그 화면이 사라지고,
나중에 그 문장을 지도할 때 **학생 화면에는 원문도 자기 해석도 남아 있지 않습니다.**
(알림함 펼치기는 승인·알림이 발생한 뒤에만 보이므로 이 상황을 해결하지 못합니다.)

## 만들 것 — 보류함 (승인 전 상시 열람)

학생 화면에 **보류 중인 문장 목록**을 상시 제공합니다. 승인 여부와 무관하게,
`sentence_approvals.status = 'held'` 인 내 문장이 있으면 그대로 남아 있습니다.

1. **학생 홈 상단 배너/카드**: "선생님 첨삭 대기 중인 문장 N개" → 누르면 보류함으로 이동
2. **보류함 화면** (`/learn/held`): 보류 문장 카드 목록
   - 문장 코드 · 보류된 시각
   - 영어 원문
   - 내가 제출한 한글해석 (처음 / 최종, 다르면 둘 다)
   - 선생님 임시 메모(4칸 서식, 있을 때만)
   - **한글 정답(마스터 해석)은 표시하지 않음**
3. 선생님이 최종 승인하면 그 문장은 보류함에서 자동으로 사라집니다.

지도 흐름: 선생님이 보류함에서 문장을 열고 → 학생은 자기 화면에서 같은 원문/해석을 보며 설명을 듣고 → 선생님이 승인 팝업에서 최종 평가.

## 속도
- 홈에서는 보류 **건수만** 세는 가벼운 count 쿼리 1건.
- 보류함 화면에 들어갔을 때만 목록 + 원문 + 내 해석을 각각 1회씩(총 3쿼리) 묶어서 조회.
- 학습 화면(SentenceLearn) 로직·쿼리는 손대지 않음 → 학습 속도 영향 없음.

## 기술 메모
- 신규: `src/pages/StudentHeldSentences.tsx`, `src/hooks/useHeldSentencesCount.ts`, 라우트 `/learn/held` (RequireAuth).
- 조회: `sentence_approvals`(status='held', 내 user_id) → 코드 목록으로 `textbook_passages.english`, `sentence_translations`(내 제출 이력) 일괄 조회.
- 표시 컴포넌트는 기존 `SentenceReviewDetail` 재사용(원문·처음/최종 해석·메모), 목록은 `held_memo` 전달.
- 홈 진입점은 `StudentHome.tsx` 상단에 카드 1개 추가.
- DB 변경 없음.
