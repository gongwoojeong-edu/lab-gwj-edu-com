# 학생 화면: 완료한 유닛도 인쇄요청 / 자료열람요청 가능하게

## 확인된 원인

`src/pages/StudentHome.tsx` 에서 "진도 범위 학습 완료" 상태(`done`)일 때는 트로피 카드 하나만 렌더링하고, 그 아래 **진도 워크북 카드(인쇄 요청 / 자료열람 요청)와 완료 유닛 탭이 통째로 렌더링되지 않습니다**. 김재원·이지호 학생이 정확히 이 상태입니다(박준언 공통영어2 1과·2과 모든 유닛 문장 100% 완료).

두 번째 원인은 목록 범위입니다. 진도 워크북에 뜨는 유닛은 "최근 학습 문장 60개"에서 역산해 만들기 때문에, 오래전에 끝낸 유닛은 목록에서 빠집니다. 그래서 지난 학습분에 대한 요청 버튼이 안 보입니다.

## 처리 방안 (모두 `src/pages/StudentHome.tsx`, 화면 로직만 수정)

1. **완료 메시지와 워크북 카드 분리**
   트로피 "진도 범위 학습 완료" 카드가 떠도 그 아래에 진도 워크북 카드와 완료 유닛 탭이 항상 표시되도록 렌더링 위치를 옮깁니다.

2. **지난 학습 유닛까지 목록에 포함**
   최근 60문장 기준 대신, 학생의 학습 기록(sentence_progress)에 존재하는 **모든 유닛**을 모아 유닛 목록을 만듭니다. 유닛 수가 많아질 수 있으므로 최근 학습 순으로 정렬하고, 기본은 최근 것 위주로 보여주되 "지난 유닛 더 보기" 토글로 나머지를 펼칩니다.

3. **지난 학습 유닛도 요청 가능**
   - 문장 100% 완료 + 워크플로 미시작 유닛 → [인쇄 요청] 버튼 노출 (시점 제한 없음).
   - 인쇄 완료(printed) 이상 상태의 유닛 → [자료열람 요청] 버튼 노출. 현재는 `printed` 단계에서만 보이는데, `workbook_submitted` / `completed`(승인 끝난 지난 유닛)에서도 요청·라이브러리 진입 버튼이 보이도록 합니다.
   - 이미 승인된 유닛은 [라이브러리] 바로가기 버튼으로 표시.

4. **완료 유닛 탭 보강**
   선생님 승인까지 끝난 유닛 목록에도 자료열람 요청 / 라이브러리 버튼을 함께 노출합니다.

## 참고

데이터 요청하신 두 학생의 박준언 공통영어2 1과·2과 전 유닛 자료 열람은 이미 승인 처리되어 라이브러리에서 바로 열람 가능합니다. 위 작업은 앞으로 학생들이 스스로 지난 유닛 자료를 요청할 수 있게 하는 화면 수정입니다.

## 기술 메모

- 대상 파일: `src/pages/StudentHome.tsx` 단일 파일 (렌더 구조 + `mainUnits` 수집 로직).
- 서버 로직 `requestMaterialView()`는 이미 `printed / workbook_submitted / completed` 를 허용하므로 백엔드 변경 불필요.
- DB 스키마 변경 없음.
