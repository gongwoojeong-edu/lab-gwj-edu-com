# 승인 대기 · "수업 자료함" 추가

## 목표
첨삭 중 반 전체에 설명할 문장을 표시해 따로 모으고, 다음 수업 때 프로젝터에 크게 띄워 설명합니다.

## 사용 흐름
1. 승인창(첨삭 화면)에 **"수업" 버튼** 추가. 누르면 담당 선생님 선택(보류처럼 마지막 선택 기억), 필요하면 짧은 메모 입력.
2. "수업" 표시는 승인·보류와 **별개**입니다. 표시한 뒤에도 평소처럼 승인/보류/재학습을 그대로 진행합니다. 학생 진도에는 영향 없음.
3. 승인 대기 화면에 **"수업 자료함" 탭** 추가 (보류함 옆).
   - 담당 선생님별로 나눠 보기 (선생님은 자기 것만, 관리자는 전체 — 보류함과 같은 규칙)
   - **책 시리즈 / 권 / 과 / 유닛**으로 검색·필터
   - 같은 문장을 여러 학생이 표시돼도 문장 하나로 묶고 "학생 N명" 표시
   - 체크해서 이번 수업용 문장만 고르기
4. **프로젝터 모드**: 고른 문장을 전체 화면 큰 글씨로 한 장씩(영어 원문 + 정답 해석 가림/보임 토글 + 메모). 좌우 화살표로 넘김. 학생 이름은 표시하지 않음.
5. 수업 후 **"수업 완료"** 처리하면 자료함에서 빠지고 완료 목록에 보관.

## 확인 필요 (승인 시 기본값으로 진행)
- 프로젝터 화면에 학생 해석(오답 예시)을 이름 없이 함께 보여줄지 → 기본: 끄기/켜기 버튼 제공
- 판서(펜) 도구를 프로젝터 화면에도 쓸지 → 기본: 기존 판서 도구 연결

## 기술 메모
- 새 테이블 `class_review_items` (sentence_id, student user_id, approval_id, assignee teacher_id, note, status open/done, created_by, timestamps) + GRANT/RLS: 교사·관리자만 접근, 학생 접근 불가.
- 승인창 `TeacherApprovalDialog.tsx`에 버튼, 담당 선생님 목록은 `heldTeachers.ts` 재사용, 마지막 선택 localStorage(교사 키).
- `PendingApprovals.tsx`에 탭 추가, 조회는 `fetchAllPages`/`fetchInChunks` 사용, 시리즈 필터는 passages→units→textbooks→series 매핑.
- 새 컴포넌트 `ClassReviewProjector.tsx` (전체화면).
- 범위 규칙 테스트: 선생님은 본인 지정분만, 관리자는 전체.
