# 보류 문장 "첨삭 보기" 화면 (학생용)

## 문제
보류(held)로 넘기면 학생은 바로 다음 문장으로 진행하기 때문에, 나중에 선생님이 티칭할 때 학생 화면에서 **그 문장의 영어 원문과 본인이 제출한 한글해석**을 다시 볼 방법이 없습니다.

## 만들 것
학생 알림함(/notifications)의 알림 카드를 **펼치기(아코디언)** 형태로 바꿔서, 펼쳤을 때만 그 문장의 내용을 보여줍니다.

펼쳤을 때 표시:
- 영어 원문
- 내가 제출한 한글해석 (첫 제출 / 최종 제출이 다르면 둘 다)
- 선생님 메모(4칸 서식 그대로 렌더)
- "이 문장 다시 열기" 버튼 (기존 동작 유지)

**한글 정답(마스터 해석)은 표시하지 않습니다.**

## 속도
- 목록을 그릴 때는 추가 조회를 전혀 하지 않습니다. 현재와 동일한 쿼리 1건뿐.
- 카드를 펼친 순간에만 해당 문장 1건을 조회하고, 한 번 불러온 것은 화면 안에 캐시해 다시 조회하지 않습니다.
- 따라서 알림함 로딩 속도·학습 화면 속도에는 영향이 없습니다.

## 학습 화면 쪽
`SentenceLearn`의 보류 대기 패널은 이미 원문 + 내 해석을 보여주고 있으므로 그대로 둡니다. 선생님 메모 렌더만 서식(4칸) 뷰로 통일합니다.

## 기술 메모
- 수정 파일: `src/pages/StudentNotifications.tsx` (펼치기 UI + 지연 조회), 공용 표시 컴포넌트 신규 1개.
- 조회: `textbook_passages`에서 `code = sentence_id`로 english 1건, `sentence_translations`에서 본인 해당 문장 제출 목록(첫/최종).
- 메모는 기존 `StructuredMemoView`를 재사용.
- DB 변경 없음, 새 인덱스 없음.
