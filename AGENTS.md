# Architecture rules
- Merge bookshelf passages through merge_passages_with_translations in one transaction; concatenate each learner's current translations in passage order and retain historical submissions so partial saves cannot delete source text.
- Keep Orbit learner eligibility in sync-orbit-english/eligibilityPolicy.ts and use it for both import and active-account cleanup; teacher-test enrollment exemptions must not grant staff privileges.
- Import explicitly designated mock-teaching staff through the trusted active Orbit staff path and create their learner profiles insert-only; synchronization must preserve learning settings and keep active staff learner profiles out of student cleanup.
- Keep automatic vocabulary difficulty and lemma-based per-unit repetition policy in extract-sentence-words/vocabularyPolicy.ts; resolve grade from the stored textbook and enforce limits in passage order so manual and import-triggered extraction share the same policy.
- Keep held coaching assignee in sentence_approvals.held_teacher_id independently of held_by; teacher inboxes filter the assignee without changing existing staff access or student progression.
- Scope pending approvals and the held box to the viewer: non-admin teachers see only their own students (student_profiles.teacher_id, unassigned students stay visible to all) and only their own held box; admins see everything. Apply the same scoping in PendingApprovals.tsx and usePendingApprovalsCount.ts so list and sidebar badge never disagree.
- Count learning-result sentences from dated student submissions/attempts, deduplicated per student and category; never count approval decisions, print actions or historical unit-context rows as new learning.
- Deliver open teaching questions through a student-scoped global listener independent of teaching sessions and the current sentence; refresh on subscription/reconnect and focus so questions sent for earlier sentences remain reachable.
- Store student-specific important sentence designations in student_passage_overrides and read them through importantSentences.ts; this preserves flags across approval attempts and shares one source with workbook generation.
- Store student-specific topic sentence designations independently in student_passage_overrides and read them through topicSentences.ts; approval controls and every syntax workbook share the saved flag without changing importance or progression.
- Keep teacher evaluation grade labels/colors in src/lib/gradeMeta.ts (a pure module with no DB or auth imports); on-screen badges and print templates both read from it, so a printed workbook can never show a grade wording the app doesn't use.
- Use paginatedQuery.ts for unbounded approval queue reads and chunk large IN filters; stable ordering and propagated errors prevent truncated queues, counts, and missing student translations.
- Keep the student analysis shading rule (verb/verbal/conjunction/special construction + teacher-required) in src/lib/analysisCore.ts mirrored by master_analysis_spots.core; shading and grading stay separate so narrowing hints never changes pass criteria.
- Store per-textbook key grammar in textbooks.key_grammar and read it via fetchKeyGrammarForUnits/fetchPassageSource so workbook front pages and the student header share one source.
- Keep class-review marks in class_review_items and read/group through classReview.ts; attendance completion atomically assigns coaching resubmission only to selected attendees and stores their completed items, enforcing teacher scope and preserving latest assignment attempts. Student approval hydration must preserve that active request rather than re-pass it. Pending approval reads (list and badge) exclude submissions with an open class mark via the class_queued_approval_marks RPC, so marks owned by other teachers also hide them.
- Deliver class-coaching resubmission through the global redo notification banner, preserve its approval assignment when opening it, and refresh same-sentence navigation; live coach approvals must read active progress requests before advancing.
- Filter class attendance candidates by every selected sentence's learning scope (both decks), unit assignments or unit learning history, matching workbook eligibility without using approval decisions.
- Classify student redo notifications in studentInbox.ts from evidence, not read_at: a later submission marks them done, an active redo flag keeps the newest one current; badge, banner and inbox share this so "read" never hides unfinished re-learning.
